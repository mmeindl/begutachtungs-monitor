# Security Policy

If you find a vulnerability in this project or on
[begutachtungs-monitor.at](https://begutachtungs-monitor.at), please report
it privately to **kontakt@begutachtungs-monitor.at** (or via GitHub's
private vulnerability reporting, if enabled) instead of opening a public
issue.

You will get a response as quickly as a one-person spare-time project
allows — usually within a few days. Please include steps to reproduce.
There is no bug bounty, but reports are credited if you wish.
